# Задания 5–7: поиск строки в текстовом файле

## Подготовка и запуск на Solaris

Из корня репозитория создайте временный демонстрационный файл. Существующий `test.txt` для этого менять не нужно:

```sh
printf 'Hello World\nThis is a test file\nFor operating systems course\nLine number four\nEnd of file\n' > /tmp/os-lines.txt
```

Соберите программы:

```sh
make -C Task5
make -C Task6
make -C Task7
```

Запуск каждой версии:

```sh
./Task5/line_lookup /tmp/os-lines.txt
./Task6/line_lookup_alarm /tmp/os-lines.txt
./Task7/line_lookup_mmap /tmp/os-lines.txt
```

Введите номер строки от `1` до числа строк, чтобы вывести её. `0` завершает программу. Для версий 6 и 7 каждая пауза на приглашении ввода ограничена пятью секундами. Таймаут можно показать командой:

```sh
sleep 6 | ./Task6/line_lookup_alarm /tmp/os-lines.txt
sleep 6 | ./Task7/line_lookup_mmap /tmp/os-lines.txt
```

Обе программы при таймауте печатают всё содержимое файла и завершаются. Для проверки пустого файла в версии 7:

```sh
: > /tmp/os-empty.txt
./Task7/line_lookup_mmap /tmp/os-empty.txt
```

Ожидаемый ответ: `File is empty.`

Сборка создаёт исполняемые файлы в папках заданий. Удалить их можно командами `make -C Task5 clean`, `make -C Task6 clean` и `make -C Task7 clean`.

## Что реализовано

| Задание | Реализация | Соответствие требованиям |
| --- | --- | --- |
| 5 | [Task5/line_lookup.c](Task5/line_lookup.c) | Открывает текстовый файл через `open`, строит динамическую таблицу смещений и длин строк чтением `read`, печатает таблицу для сверки, запрашивает номер строки, переходит к её началу через `lseek`, читает заданное число байтов через `read` и выводит строку через `printf`. Номер `0` завершает цикл; неверные и выходящие за диапазон номера обрабатываются отдельно. |
| 6 | [Task6/line_lookup_alarm.c](Task6/line_lookup_alarm.c) | Сохраняет таблицу и поиск из задания 5. На каждом приглашении включает `alarm(5)`. Если сигнал приходит раньше завершения ввода, обработчик пишет сообщение, возвращает файловую позицию к началу, копирует весь файл через `read`/`write` и завершает процесс через `_exit`. При успешном вводе будильник сразу отменяется. |
| 7 | [Task7/line_lookup_mmap.c](Task7/line_lookup_mmap.c) | Получает размер файла через `fstat`, отображает непустой файл `mmap(PROT_READ, MAP_PRIVATE)`, строит ту же таблицу непосредственно по отображённым байтам и выводит выбранную строку `fwrite`. Таймаут аналогичен заданию 6, а полный файл обработчик пишет из отображения через `write`. Нулевой размер обрабатывается до `mmap`; при обычном завершении вызывается `munmap`. |

У каждой папки есть Makefile с `gcc`, флагами `-std=c99 -Wall -Wextra -pedantic -O2` и целями `all`/`clean`. Длина строки измеряется в байтах и включает `\n`, если он есть в файле. Последняя строка без завершающего перевода строки тоже попадает в таблицу.

Обработчики `SIGALRM` не используют stdio: для асинхронного вывода они применяют `write` и завершаются через `_exit`, как требует условие. В интерактивном цикле запрос сбрасывается до установки таймера, поэтому отсчёт относится к ожиданию ответа.
