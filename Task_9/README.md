Сборка: `make`

Запуск: `./task9 file.txt`, где file.txt — длинный текстовый файл.

Дочерний процесс запускает cat. Последняя строка родителя выводится после завершения дочернего процесса.

Первая часть задания без ожидания: `gcc -std=c99 task9_before_wait.c -o task9_before_wait`, затем `./task9_before_wait file.txt`.

Проверено на macOS. Проверка на учебном Solaris пока не выполнена.
