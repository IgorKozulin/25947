# Задания 1–7 по операционным системам

Программы написаны на C99 с POSIX-интерфейсами для Linux и Oracle Solaris 11.4. Каждое задание находится в своей папке `task1` … `task7` в корне репозитория. Папка `lab1` содержит ранее существовавшее нулевое задание. Сборка из корня репозитория: `make` (используется утилита `c99`). Одно задание можно собрать командой, например, `make task5/task5`. Если на машине установлен только GCC, используйте `make CC=gcc`. Проверка: `make test` (нужен Python 3). Сборка и тесты выполнены в Ubuntu через WSL; на Solaris запуск нужно проверить на целевой машине.

| № | Исходник | Запуск |
|---|---|---|
| 1 | `task1/main.c` | `./task1/task1 -p -i -U1024 -u` |
| 2 | `task2/main.c` | `./task2/task2` (текущее время Калифорнии) |
| 3 | `task3/main.c` | `./task3/task3 private.txt` |
| 4 | `task4/main.c` | `./task4/task4` (вводить строки, строка с начальной точкой завершает ввод) |
| 5 | `task5/main.c` | `./task5/task5 task5/example.txt` |
| 6 | `task6/main.c` | `./task6/task6 task6/example.txt` |
| 7 | `task7/main.c` | `./task7/task7 task7/example.txt` |

В задании 2 необязательный аргумент вида `2026-01-01T20:00:00Z` позволяет проверить конкретный момент времени. Программа учитывает переход на летнее время в Калифорнии: зимой выводит PST, летом PDT.

Для задания 3 подготовьте файл от имени владельца: `printf 'secret\n' > private.txt && chmod 600 private.txt`. Программа сначала выводит UID и пробует открыть файл, затем вызывает `setuid(getuid())` и повторяет оба действия. При запуске самим владельцем обе попытки успешны. Для демонстрации различия UID понадобится запуск другим пользователем с правом исполнения файла и установленным владельцем битом setuid (`chmod u+s task3/task3`). На файловой системе, где setuid отключён, этого различия не будет.

Для заданий 5–7 номер строки начинается с 1, ввод `0` завершает программу. Задания 6 и 7 дают пять секунд на каждый ввод; по истечении времени печатают файл целиком и завершаются. Задание 7 читает файл через `mmap`, не используя `read`/`lseek` для доступа к нему.
