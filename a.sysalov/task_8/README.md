Сборка: make
Запуск: ./locked_editor file
Обязательная блокировка: ./locked_editor --mandatory file
Редактор задается переменной EDITOR, по умолчанию vi.

Программа устанавливает F_WRLCK на весь файл через F_SETLK. Если другой
экземпляр уже держит блокировку, программа сообщает об ошибке и не запускает
редактор. Проверять нужно на одном и том же файле, доступном группе на запись.

При рекомендательной блокировке второй экземпляр этой программы не получает
блокировку, но обычный редактор, не проверяющий блокировки, может менять файл.
Блокировка относится к открытому файлу: замена файла через переименование
может обойти ее. Для опыта нужен редактор, сохраняющий файл на месте.

Режим --mandatory устанавливает S_ISGID и снимает S_IXGRP, сохраняя исходные
права до завершения редактора. Сам вызов fcntl остается тем же. Реальное
обязательное захватывание требует поддержки ОС и файловой системы; одни
измененные биты доступа не доказывают, что оно работает.

Если обязательная блокировка действует, редактор, запущенный через system,
работает в другом процессе и его чтение/запись конфликтует с блокировкой
родителя. Редактор может ждать снятия блокировки, а родитель ждет редактор.
Для завершения опыта нужно завершить редактор со второго терминала.
На локальной машине проверена рекомендательная блокировка; обязательную
блокировку следует проверить на целевой Solaris.
