Задача 32: Unix domain sockets и POSIX AIO.

Сервер ставит aio_read() для каждого клиента. Завершение чтения сообщает
SIGUSR1 (SIGEV_SIGNAL), новые подключения — SIGIO слушающего сокета.
В основном цикле aio_error() проверяет результат, aio_return() получает его,
после обработки запускается следующий aio_read(). Сигналы ожидаются через
sigsuspend(), без select(), poll() и периодического опроса по таймеру.
Клиентские сокеты блокирующие. Запрос на один байт позволяет получать
данные сразу и на Solaris. Строки буферизуются до перевода строки или EOF.
При остановке сервер отменяет и дожидается завершения оставшихся запросов.

Сборка на Solaris: make LDLIBS="-lsocket -lnsl -lrt"
Сборка на Linux: make LDLIBS="-lrt"
На macOS код компилируется, но aio_read() для сокетов локально возвращает
Illegal seek. Для запуска этого варианта используйте Solaris или Linux.

Первый терминал: ./server
Второй терминал: ./client Alice
Третий терминал: ./client Bob

Каждый клиент сам передает три строки с интервалом 0.5 секунды и завершается.
Имя по умолчанию — client. Можно указать путь: ./client Alice /tmp/task32.sock
Сервер запускается с таким же путем: ./server /tmp/task32.sock
Сервер работает до Ctrl+C. Одновременно поддерживаются до 64 клиентов.
Проверка на Linux/Solaris: python3 check_aio.py

POSIX AIO: https://docs.oracle.com/cd/E53394_01/html/E54815/chap7rt-48.html
