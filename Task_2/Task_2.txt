## 2. Ключевые концепции для понимания

• setenv("TZ", "...", 1): Устанавливает переменную окружения TZ (Time Zone) для текущего процесса. Это заставляет функции времени игнорировать системные настройки сервера и использовать указанный пояс.
• tzset(): Инициализирует библиотеку C в соответствии с новой переменной TZ. Без этого вызова изменения TZ не вступят в силу до следующего запуска программы.
• localtime(&now): Преобразует абсолютное время (UTC) в локальное, учитывая правила выбранного пояса (включая переходы на летнее время).
• struct tm: Структура времени. Важно помнить:
  - tm_mon: месяцы от 0 до 11 (нужно прибавлять 1).
  - tm_year: годы от 1900 (нужно прибавлять 1900).
  - tm_isdst: флаг, равный 1, если действует летнее время.
• tzname[]: Глобальный массив строк. tzname[0] — название стандартного времени (PST), tzname[1] — летнего (PDT).

ЗАМЕЧАНИЕ О ЛЕТНЕМ ВРЕМЕНИ:
Калифорния использует два режима:
1. PST (Pacific Standard Time) = UTC - 8 часов (зима).
2. PDT (Pacific Daylight Time) = UTC - 7 часов (лето).
Если использовать код "PST8", программа всегда будет отнимать 8 часов, что приведет к ошибке в 1 час в период действия летнего времени. Поэтому правильно использовать географическое название "America/Los_Angeles".

## 3. Основные библиотеки

#include <stdio.h>        // printf
#include <time.h>         // time_t, struct tm, time(), localtime()
#include <stdlib.h>       // setenv()

## 4. Алгоритм решения

1. Установка часового пояса:
   - Используйте setenv("TZ", "America/Los_Angeles", 1);
   - Сразу после этого вызовите tzset(); для применения настроек.

2. Получение времени:
   - Объявите переменную time_t now;
   - Получите текущее время: time(&now);

3. Конвертация в локальное время:
   - Объявите указатель на структуру: struct tm *sp;
   - Преобразуйте время: sp = localtime(&now);

4. Форматированный вывод:
   - Используйте printf с форматом "%02d/%02d/%04d %02d:%02d %s\n"
   - Не забудьте скорректировать месяц (+1) и год (+1900).
   - Для названия пояса используйте tzname[sp->tm_isdst].

## 5. Создание файла ex_time.c

nano ex_time.c

Вставьте базовую структуру и реализуйте алгоритм из пункта 4.
Сохранение: Ctrl+O, Enter. Выход: Ctrl+X.

## 6. Сборка и тестирование

Убедись, что Makefile настроен на сборку ex_time.c. Создайте или отредактируйте файл Makefile:

CC = gcc
CFLAGS = -O2
TARGET = ex_time
SRC = ex_time.c

all: $(TARGET)

$(TARGET): $(SRC)
	$(CC) $(CFLAGS) -o $(TARGET) $(SRC)

clean:
	rm -f $(TARGET)

.PHONY: all clean
_____________________
Команды для запуска:
make clean
make
./ex_time
